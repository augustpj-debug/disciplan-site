# Disciplan pages

The public pages for [Disciplan](https://github.com/augustpj-debug/disciplan):
the privacy policy, the consumer health data privacy policy, the terms of use,
and a support page.

Live at **https://augustpj-debug.github.io/disciplan-site/**

These files are **generated** from the app's own repository and copied here. Do
not edit them by hand — edit the Markdown in the app repo's `docs/` folder,
run `node scripts/build-site.mjs`, and copy the result over.

All three policies are currently marked **draft, pending legal review**.
